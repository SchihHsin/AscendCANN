## 证据方法
- 本轮读取并归档 14 个公开官方页面，源文件为 source-0.txt 至 source-13.txt。
- 官方文档可证明“公开写明的能力/规则”，不等于本轮已在账号内实测。
- 官网描述和数字以营销主张/示例处理，不能当作实际效果。访客识别有限定合规流量与可能联系人；不能把公司级行为说成某个人的确定意图。
- Email ICP Website Visitors 明确 Drafts only, never auto-sent；不能把该工作流写成站内一键自动发送。
- GSC 工作流声明观察修改后 14–28 天；尚未验证实际收益或因果归因。
- Publishing 区分按站点的 Preview only 与 Preview + Production。定时执行不自动授予发布权。
- Ploybooks 的 working memory 可选，自建默认关闭。不要与工作区偏好记忆混为一谈。
- CLI 与集成文档对 Code Sync 的套餐要求表述不同（Pro / paid）；材料不作套餐判断。
- Webhook 已接收不等于任务成功；暂停保留历史、仅记录模式不触发工作流。
- 对整个产品的交互组合做分析，不声称穷尽产品功能或证明行业独创性。
- 本次页面中的关系图和表格是分析重绘，均明确标注，未冒充截图。
- 学习概念为 L 级待验证假设，非 Ploy 教学功能，未接真实 AI / IDE / NPU。
