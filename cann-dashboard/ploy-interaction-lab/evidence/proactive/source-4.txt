Integrations
Connect the tools you already use to your Ploy workspace.
Ploy connects to 40+ external services so your marketing site can read from and write to the tools your team already runs on. Connect an integration once from
Settings → Integrations
 in the Ploy dashboard, and Ploy&#x27;s Agent can pull data, sync records, draft messages, and trigger workflows on your behalf.
Available Integrations
Browse by category — expand any group to see what each integration does.
Design & Brand
Integration
What It Does
Figma
Extract brand tokens (colors, typography, spacing) from a Figma file, export frames and images, and use Figma designs as reference for Ploy&#x27;s Agent when building pages.
Analytics & SEO
Integration
What It Does
Google Analytics 4
Query your GA4 data from inside Ploy — active users, sessions, top pages, acquisition channels, and more.
Google Search Console
Monitor search performance — keyword rankings, impressions, clicks, CTR, and indexing status.

Pull keyword, ranking, and competitor data to inform content, on-page optimization, and AEO strategy for your pages.

Ploy Site Development
Each Ploy Site gets its own repository hosted under the
github.com/ployspace/
 org — one repo per site, built on Astro and Tailwind. This is managed entirely by Ploy and is separate from any GitHub account or organization you own.
Integration
What It Does
Code Sync (via GitHub)
Sync your site&#x27;s
@ployspace
 repository locally
, iterate on your Ploy site in your own editor, then sync your changes back up to Ploy when you&#x27;re happy with them. Ploy&#x27;s Agent commits its edits to the same repo, so your dev team and the Agent stay in lockstep. Requires the Pro plan.

How to Connect
Navigate to
Settings → Integrations
 in the Ploy dashboard.
Find the integration you want and click
Connect
.
Complete the OAuth authorization flow with the service provider.
Once connected, the integration is available immediately — Ploy&#x27;s Agent can read from (and in some cases write to) the connected service.
Tip:
 You can also ask Ploy&#x27;s Agent to connect an integration — &quot;Connect our Google Analytics&quot; or &quot;Link our Figma file.&quot;
Using Integrations with Ploy&#x27;s Agent
Once connected, integrations become part of Ploy&#x27;s Agent&#x27;s toolkit. Examples:
Figma:
 &quot;Extract our brand from this Figma file: [URL]&quot;
GA4:
 &quot;How many sessions did we get this week?&quot;
GSC:
 &quot;What keywords are we ranking for on the blog?&quot;
Code Sync:
 &quot;Sync from GitHub&quot; — pulls your team&#x27;s latest local commits into the Ploy sandbox
HubSpot:
 &quot;Enrich this week&#x27;s visitors against our CRM&quot;
Notion:
 &quot;Pull our support docs from Notion&quot;
Slack:
 &quot;Post a daily traffic digest to #marketing&quot;
Ad platforms:
 &quot;Summarize last week&#x27;s spend and conversions across Google, Meta, and LinkedIn&quot;
Ploy&#x27;s Agent knows which integrations are connected and will suggest connecting new ones when they&#x27;d be useful.
Permissions & Security
Each integration uses
OAuth
 — Ploy never stores your passwords.
You can
disconnect
 any integration at any time from Settings.
Integrations request only the permissions they need (e.g., read-only for analytics, read-write for GitHub).
