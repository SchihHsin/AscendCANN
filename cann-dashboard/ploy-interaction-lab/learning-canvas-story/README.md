## 内容边界

- 两条故事线是目标体验提案；原图保留早期设计，不是当前Demo截图或真实执行证据。图中仍可能有历史术语与布局，现行共通行为以20–52页为准。
- 不新增学习中心或强制学习组；解释、试改与学习按需发生在原任务中，右侧不常驻自由画布。
- 统一对象身份、查看与管理动作；图解、代码、网页、Diff、视频按业务组合正文，无需全部走修改或检查流程。
- 当前Demo已实现两任务的共通管理，详见第52页。20–29页说明界面架构，30–50页记录本地演示中的具体状态；AddCustom与图像推理是共通规则的两个验证案例，不是所有业务必须经过的线性排障流程。参数、提案、应用及核对均为浏览器演示，不代表真实工程写入或执行。当前已加入显式关联自动画线与语义缩放；主题仍为两案例预置，不做任意AI语义归组。真实外部后台结果晚到、编辑冲突及收起期间到达新结果尚未实拍；新结果不抢焦点的框架说明不能据此当作真实并发验证。视频互动的更完整故事、图像专属主动提示、能力匹配及官网／GitCode协作仍需补齐，不属于本轮新增实拍。A1–A5学习起步已扩展为学习层级自由画布，见本README末尾记录。
- 示例预览、修改应用、范围核对分别记录；没有真实工程写入、Python／CANN编译、模型推理或NPU验证，不声称完整任务已运行成功。
- 目标旅程与设计收益仍待用户回放验证；本地操作取证不等于用户效果研究。
