| 收起留概要，再打开不丢现场 | 已改，会话内 | 卡片/组可收起；深入内容关闭后仍在总览。正常往返保留参数、阅读状态、总览滚动及自由视口；内容高度改变时位置可能收缩。 |

| 多次尝试/核对嵌套，旧结果保留条件 | 已改，会话内 | 记录挂在父内容下，带时间、输入/容差；取消的提案仍可看。恢复不重跑，旧通过不等于当前条件通过。 |
| 就近入口或一句话唤醒历史 | 部分已改 | 对话/对象入口可恢复；有限本地语句可找回当前现场或列历史候选。未接任意自然语言的语义检索。 |
| 最近使用和相关内容优先 | 未完整实现 | 当前目录按预置顺序，部分历史按产生顺序倒序；没有统一记录最近访问并排序/推荐的机制。 |
| 固定参考跨步骤连续保留 | 部分已改 | 图解快照固定、自由画布位置固定和普通并排各有局部能力；没有统一的跨视图固定参考管理。 |
| 整个右区按需关闭，将宽度归还对话 | 未改完整 | 可以收起单项并回总览、拖三栏宽度；整个右栏仍在布局中。“关闭内容”不能称为“关闭右区”。 |
| 刷新/关闭页面后恢复 | 未改 | 目前为 React 会话内状态。刷新、再次访问后的目录、参数、记录及布局恢复均未实现。 |
| 跨任务复用 | 未改 | 两任务状态隔离已做；引用到其他任务并确认适用条件的流程未做。 |
