# 六题导读 3D 插图

## 用途与生成方式

用于精简报告“六个问题导读”页的 2×3 浅色场景卡。六张 PNG 均为独立概念插图，1254×1254，带透明背景；不是访谈、产品或运行证据。使用内置 `image_gen` 分别生成，没有使用 CLI/API fallback。

## 共用提示词

- Use case: `stylized-concept`
- Asset type: 六题开发者工作流报告卡片中的独立插图；透明背景。
- Style/medium: 克制、精致的 3D editorial miniature；圆润造型、哑光陶瓷与柔触材质、干净倒角；六张构成同一视觉家族。
- Composition/framing: 方形构图、居中、四分之三等距视角、中近景、统一物体尺度与镜头角度、透明留白、缩小后仍能识别。
- Lighting/mood: 左上柔光、轻微接触阴影、平静可靠。
- Color palette: 靛蓝、柔和蓝、青绿，少量暖琥珀色；中等饱和度，在浅灰卡片上保持轮廓对比。
- Text: 无。
- Constraints: 真实透明背景；无文字、字母、数字、商标、水印、边框或背景平面；不做 UI 截图，避免杂乱。

## 六张主题提示

1. `01-capability-selection.png`：三块不同的开发能力模块（文档、工具／齿轮、连接节点）围绕一个任务方块组装成实用工具组合。
2. `02-next-action-guidance.png`：开发者依据经验指向分岔路径中的一条，抽象 AI 助手跟随；错误方块位于分岔之前，选中路径清楚可见。避免恐怖机器人、可读代码和繁杂场景。
3. `03-result-verification.png`：生成结果方块置于测试台上，以放大镜检查；旁边有绿色通过标记与琥珀色证据缺口标记。避免可读代码、仪表盘和“所有检查已通过”的暗示。
4. `04-learning-transfer.png`：开发者先观察已解出的几何方块，再独立调整形状不同的新方块；同一紧凑场景内展示学习者与两种形状。避免教室、教师、带字书籍和毕业符号。
5. `05-team-handoff.png`：两位开发者传递半透明交接夹，里面用三个抽象标记表示已选方案、尝试过的替代方案和未解决风险。避免可读文档、会议室和多余人物。
6. `06-knowledge-reuse.png`：一条任务经验从个人工作方块进入由节点连接的共享知识架，另一位开发者取回复用。避免可读文字、大型图书馆和人群。
