DIRECTION 01

可验证任务合约
Verified Task Contract

路径生成后先出现一份可执行合约，任务每一步产生证据回执；完成度从“看过多少节点”改为“多少关键验收项已通过”。

任务合约
目标、版本、硬件、输入与完成条件可见。
证据回执
命令、输出、日志、diff 与产物持续关联。
可解释完成
不仅测试通过，还能证明为何通过、适用哪里。
01任务简报目标与边界
02环境锁定版本 / 硬件
03执行与采证日志 / diff / 产物
04验收回执通过 / 待修 / 升级
真实环境的先进性不在“能运行”，而在状态可恢复、结果可复现

DIRECTION 03

苏格拉底式共学 Agent
Cognitive Apprenticeship

Agent 不以回答问题为终点，而持续观察代码、运行和错误证据，控制何时追问、何时给提示、何时撤掉脚手架。

先预测
运行前要求用户判断输出、风险或性能。
最小提示
失败后只给足够跨过当前障碍的线索。
提示衰减
连续成功后主动减少帮助，验证独立完成。
01提出假设预测结果
02执行任务代码 / 环境
03观察证据输出 / 错误
04调节脚手架追问 / 提示 / 撤除
技能图谱只有绑定最新任务证据，才配得上“个性化”
