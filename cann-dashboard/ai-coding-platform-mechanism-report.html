OUTPUT · TRUST

ORCHESTRATION · SLA

交付通道可多样： MCP 适合在线工具调用，Skill 适合方法与脚本装配，API / CLI 适合稳定系统动作，网页适合人工审阅，专家服务处理高不确定性。合同不应绑定单一通道。
