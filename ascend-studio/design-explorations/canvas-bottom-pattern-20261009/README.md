## 本轮规则

右侧画布的装饰是底部背景花纹，表达连续、交汇与连接，不做实色体块或独立插画位。

- 浅淡细曲线沿底部展开，局部交汇、分叉并继续延伸。
- 沿线少量浅蓝紫、薄荷和淡粉渐变，向上及边缘逐渐消失。
- 不参与布局、不接收点击，不挤占画布空间。
- 不画节点、箭头、端点圆点或标签，也不将线连接到真实卡片。
- 文字、卡片、小地图和工具仍清晰；左侧档案叠片与中间交汇氛围延续。
