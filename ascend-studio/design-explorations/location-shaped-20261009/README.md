## 造型规则

统一渐变色、通透材质和柔和折射，按位置设计形状：

- 左侧底部：紧凑折面，成为小装饰锚点，避开项目任务行和页脚文字。
- 对话顶部：横向低矮光带，顺着水平空间展开，留清晰标题与正文底色。
- 画布右缘：单一纵向弧面，局部裁出画面，避开内容块与工具栏。

三处分别采用尖角折面、柔软长带、大曲面，轮廓、方向与比例不同。保留现有HTML框架及交互；生成文字不作为内容源码或技术结论。用户尚未确认最终落地方向。
