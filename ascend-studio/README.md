- `npm run build`：保留原项目的可选Sites构建能力。
- 修改后应将本目录源码、`ascstudio/`静态产物和根仓交接记录一起提交并立即推送。

## 范围

保留项目任务、对话、工作区三栏。右侧默认直接查看代码、解释、结果、Diff或参考网页；需要整理材料时再打开自由画布。支持任务与对话操作、示例试改、范围结果、Diff审阅、示例应用和复核；画布可平移、缩放、移动对象、调整尺寸、固定、折叠、收纳与恢复。

这是问题02的设计提案。AI答复与范围算例在浏览器本地演示，未连接真实AI/NPU，不修改实际项目。页面状态仅保存在当前会话，刷新恢复初始状态。

## 栏宽调整

左侧项目栏右边缘中点的小胶囊可收起/展开项目栏。拖动两条栏间分隔线分别调整相邻两栏宽度；双击分隔线恢复默认布局。收起再展开保留当前页面中已调整的宽度。

对话装饰底图位于顶部conversation-header左上角，原PNG局部裁切，保留轻薄曲面与浅蓝紫/粉杏渐变，轻微模糊后向右/下渐消，不占位。左侧和对话两处底图共享25%不透明度。

对话正文随当前栏宽铺满，左右边距随栏宽在12–24px间变化；内容超过760px时整条内容流居中，两侧对称留白。AI文字左对齐铺背景，用户气泡在内容流内靠右。输入框在特别宽时使用同一760px上限并居中。

排版按对话栏自身宽度适应：460px以下将下一步说明放到标题下；440px以下输入工具和模型/发送分两排。建议按钮自动换行，长文本可断行，任务标题过长时省略，所有操作入口仍保留。字号不随拖动缩小。


## 按需打开画布

- 默认打开问题02的只读索引范围示例，不预置画布标签。
- 工作区右上角工具菜单的“打开画布”打开空画布或恢复已有画布；对话、内容工具栏与材料选择中的“在画布中整理”只加入相关材料。
- 普通材料以对象名称打开标签，两份材料可以直接并排查看；关闭画布回到此前内容或并排现场，保留材料、位置、尺寸与缩放。卡片的“展开查看”打开完整查看器，可以从标签或“返回画布”恢复。
- 草案、尝试与Diff共用任务数据；后台结果只新增未读提示，不抢占当前内容、不自动加入画布。切换任务保留当前页面会话中的查看状态。
- 官方参考使用仓内已有的Ascend C概览URL，提供网页地址、前进/后退、重载与外部打开。原站是否允许嵌入由原站决定；没有将iframe加载事件当成访问成功。
