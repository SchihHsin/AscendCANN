## 已确认的交互决定

- 路径布局通过无文字的 icon tab 在整体左右布局与上下布局之间切换；icon 应表达布局方向，不加文字标签。
- 默认使用左右布局，路径在左侧；用户可切换到上下布局。
- 切换只改变路径组的整体摆放，不改变学习阶段、内容、参数或进度。
- 用户已授权进入 Demo 实施阶段。该授权不表示实现或 QA 已完成。
