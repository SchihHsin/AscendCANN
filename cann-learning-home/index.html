目标：通过典型算子实践，掌握从性能基线、瓶颈分析到分步优化与精度校验的调优流程。

类别 序号 课程 课程内容 样例链接
Vector 类 8 Vector 算子优化 逐元素、归约、归一化与路由算子的 RegBase 改写、融合、多核并行及访存优化 GELU / Softmax / RmsNormQuant / KvRmsNormRoPE / MoeInitRouting
Cube 类 9 矩阵乘算子优化 矩阵乘与分组矩阵乘的 Tiling、数据搬运、尾轮负载均衡及低精度量化 MatMul / Grouped MatMul
CV 融合类 10 Cube/Vector 融合优化 极简 FA 的 CV 核融合优化实践、全量化 FA 实现、注意力残差的模板选择与两阶段流水，以及 KDA 的 Chunkwise 并行 FlashAttnLite / FIA / AttnRes / Kimi Delta Attention Lite
通算融合类 11 通信与计算融合优化 MoE Token 分发与合并中的通信、计算融合及性能优化 MoE Dispatch & Combine
专题类 12 SIMD VF、SIMT 与 Scalar 优化专题 SIMD VF 广播、归约与数据变换；SIMT 不规则访存与并行计数；ScalarBound 诊断及标量开销优化 SIMD VF / VF 数据变换 / SIMT Scatter / SIMT Histogram / Scalar

实践入口：cann-samples 是 CANN 算子实战样例与性能调优知识库，提供算子实现、优化讲解及编译运行与精度校验示例，可从上表或性能优化样例总览选择学习内容。

学习方式：

  1. 克隆仓库，按仓库首页的环境部署指南配置 CANN 与依赖。
  2. 按所选样例 README 在本地编译执行，完成精度校验并记录性能基线。
  3. 结合优化文档阅读源码；有分步版本的样例可逐版对比，理解各项优化的作用。
  4. 尝试修改 Tiling、数据搬运或流水安排，重新编译、校验精度并对比性能。

适用芯片、CANN 版本和运行命令以对应样例说明为准。
