# Ascend Studio · 口袋新知

面向手机的小程序交互 Demo，以知识卡推荐为首页，关联电脑端任务。手机上全屏体验；电脑端以小程序窗口呈现，便于评审。独立发布入口：`/AscendCANN/ascstudio-mini/`。

## 体验路径

1. 发现：搜索或筛选知识点，从任务上下文进入知识卡，也可以换一组推荐。
2. 知识卡：操作图解、回答理解题、收藏、标记「感兴趣」或「还没弄懂」，编辑并保存任务小结。
3. 每周速览：选择昇腾开发、训练调优、算子实践或 AI 应用；用一条重点资讯和两张按兴趣 / 疑问优先排序的短卡片，模拟微信授权与服务通知点击回流。
4. 任务：切换推荐上下文，查看相关知识和已保存小结，复制小结与问题后到电脑端继续。
5. 我的：查看收藏、已理解知识与任务小结，刷新后保留。

七张知识卡覆盖扩展效率、梯度同步、有效 Batch、混合精度、并行策略、尾块和输入布局。吞吐、梯度等值用于概念演示，内容附公开延伸阅读。周报示例内容为静态策划素材，不代表实时资讯。任务、推荐、兴趣标记、主题偏好、订阅状态与交互均在本地运行；相关状态存储在当前浏览器 localStorage。电脑端接续采用显式复制，不代表跨设备后台同步或已接入微信后台。

普通订阅消息不等于持续周推送。真实周期发送需要小程序类目符合平台要求并申请可用的长期订阅模板；当前页面只演示授权、通知和阅读回流。

## 文件

- `index.html`：页面与手机预览壳。
- `app.js`：路由、推荐、图解、收藏、小题、兴趣信号、每周速览和任务小结。
- `knowledge.js`：知识内容、任务关联、周报示例主题和公开阅读链接。
- `styles.css`：独立样式与手机适配。
- [知识供给侧服务蓝图](./knowledge-provider-map.html)：独立材料，说明内容资源、Knowledge Unit、发现与调用接口、治理和建设顺序；这是目标方案，不代表 Demo 已接入真实后端。

这是浏览器交互原型，可用于小程序设计评审。原生微信小程序工程及平台发布不在本版内。

本目录为构建免依赖的静态页面，使用 HTTP 静态服务器预览。JS 校验可执行 `node --check app.js` 和 `node --check knowledge.js`。
