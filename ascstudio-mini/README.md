# Ascend Work · 口袋新知

面向手机的小程序交互 Demo，以知识卡推荐为首页，并把电脑端知识口袋、微信即时送达和每周速览串成一条连续体验。桌面评审为七页：先看电脑端入口，再看微信通知、手机短读、理解状态回写、定期回访，最后回到自主发现。手机界面随讲解同步切换。独立发布入口：`/AscendCANN/ascstudio-mini/`。

电脑端评审样机按 **HUAWEI Pura X View 阔直板**呈现，单屏、无折叠结构。标准桌面外框为 420×696 CSS px，按官方机身长 144.1 mm、宽 87.0 mm 的比例近似；外框不是手机工业设计的精确复刻。顶部状态栏按 HarmonyOS 常见信息编排做概念示意，不声称是实机截图。[官方规格](https://consumer.huawei.com/cn/phones/pura-x-view/specs/)

## 体验主线

评审第 1 点默认打开电脑端现有的「图像推理调试」任务：Agent 已解释模型要求 NCHW、当前输入为 NHWC 的问题，用户可以直接把这段回答收进知识口袋。用户再选择「感兴趣」或「还没弄懂」作为学习信号，并决定立即发到微信或加入定期速览。即时路径继续到微信消息列表、手机短读卡与「我看懂了」状态回写；定期路径继续到主题与时间设置、每周速览。最后回到小程序「发现」，展示离开具体任务后仍可继续探索的核心学习体验。

桌面与手机之间的“知识口袋”承接跨端送达。兴趣和存疑标记记录用户后续想看什么、需要补充什么；它们会影响每周速览中的个性化知识卡，不会直接发送消息。两个送达按钮才会触发发送动作：「加入定期速览」把内容排进后续速览；「发到微信，现在看」立即在手机样机的微信列表生成服务通知。知识口袋默认展示三条策划示例，点击任一条可展开其来源、正文、学习标记和送达操作；展开区与条目连成一个卡片组。

桌面评审控件只存在于设备样机外框：指针移至屏幕下沿显示翻页、总览和全屏工具栏；移至右侧显示七个设计点跳转。第 1、4 点并排嵌入电脑端 Demo 与手机样机，电脑端可实际切换任务与知识口袋；从知识口袋选择即时送达后，第 2 点手机微信列表会显示同一条内容。键盘支持 ← / →、Page Up / Page Down、Home / End，O 打开总览、F 切换全屏。地址可用 `?point=5#review-weekly-settings` 直达定期回访设置演示。手机视口不显示这些评审控件，也不增加小程序入口。

## 体验路径

1. 电脑端知识口袋：从 Agent 回答或学习内容收纳知识，展开条目，标记兴趣或存疑，再选择送达方式。
2. 即时通知：选择「发到微信，现在看」后，微信会话列表出现这条知识的服务通知。
3. 手机短读卡：阅读内容与关联任务，点「我看懂了」记录状态。
4. 回到电脑任务：知识口袋对应条目同步为「已理解」，继续原任务。
5. 定期回访设置：选择关注主题、接收星期和时间并确认订阅。
6. 每周速览：一条昇腾开发重点资讯，加两张优先参考已安排内容与学习标记的知识卡。
7. 自主发现：回到小程序核心学习入口，从搜索、分类和推荐卡继续探索。

原有的任务关联、知识图解、小练习和学习记录仍在手机端保留；它们集中呈现在第 7 点的「发现」入口中，作为从电脑端任务回访扩展到自主学习的下一步。

七张知识卡覆盖扩展效率、梯度同步、有效 Batch、混合精度、并行策略、尾块和输入布局。吞吐、梯度等值用于概念演示，内容附公开延伸阅读。周报示例内容为静态策划素材，不代表实时资讯。任务、推荐、兴趣标记、主题偏好、订阅状态与交互均在本地运行；相关状态存储在当前浏览器 localStorage。桌面与手机样机通过同源 localStorage 在同一浏览器中模拟共享口袋；这不代表已实现不同设备间的账户同步。电脑端打开手机短读页和微信通知均为页面交互，未接入微信后台。

普通订阅消息不等于持续周推送。真实周期发送需要小程序类目符合平台要求并申请可用的长期订阅模板；当前页面只演示授权、通知和阅读回流。

## 文件

- `index.html`：页面与手机预览壳。
- `app.js`：路由、推荐、图解、收藏、小题、兴趣信号、电脑端知识口袋短读、微信通知、每周速览和任务小结。
- `knowledge.js`：知识内容、任务关联、周报示例主题和公开阅读链接。
- `styles.css`：独立样式与手机适配。
- `evidence/knowledge-pocket-entry-crop.png`：电脑端知识口袋界面的历史截图裁切。
- [知识供给侧服务蓝图（7 页可视化汇报）](./knowledge-provider-map.html)：独立的 Report PPT 风格材料。封面和学习发现资源卡使用内容图；供给链路、Demo 楼层映射、Knowledge Unit、交付通道与 P0–P2 建设顺序分别用流程图、字段结构图、分流图和时间轴表达。图片位于 `assets/knowledge-resources/`；Tabler 图标的 MIT 许可随资源保存。材料描述目标服务方案，不代表 Demo 已接入真实后端。
- `evidence/home-desktop.png`：核心学习章节与 HarmonyOS 风格状态栏样机。
- `evidence/review-overview-desktop.png`：核心学习优先的旧七点版总览历史截图；当前七点顺序可在桌面总览中交互查看。

这是浏览器交互原型，可用于小程序设计评审。原生微信小程序工程及平台发布不在本版内。

本目录为构建免依赖的静态页面，使用 HTTP 静态服务器预览。JS 校验可执行 `node --check app.js` 和 `node --check knowledge.js`。
