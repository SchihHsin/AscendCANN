# Ascend Studio · 口袋新知

面向手机的小程序交互 Demo，以知识卡推荐为首页，关联电脑端任务。手机上全屏体验；电脑端以小程序窗口呈现，旁边按两个章节讲解八个设计点，手机界面随讲解同步切换。独立发布入口：`/AscendCANN/ascstudio-mini/`。

电脑端评审样机按 **HUAWEI Pura X View 阔直板**呈现，单屏、无折叠结构。标准桌面外框为 420×696 CSS px，按官方机身长 144.1 mm、宽 87.0 mm 的比例近似；外框不是手机工业设计的精确复刻。顶部状态栏按 HarmonyOS 常见信息编排做概念示意，不声称是实机截图。[官方规格](https://consumer.huawei.com/cn/phones/pura-x-view/specs/)

## 体验主线

评审先看核心学习体验：从当前开发任务发现相关知识 → 在知识卡里用图解与小题学懂 → 把进度、小结和问题带回任务并在电脑端继续。主动回访章节先展示电脑端入口：从 Agent 回答或当前学习内容收进知识口袋，标记关注或存疑，再选择即时送达或定期速览；接着展示微信列表的新消息、手机短读卡、每周速览和订阅管理。推送是重新进入学习的途径，不是小程序全部体验。手机入口默认打开「发现」；微信消息列表仍可从桌面评审总览进入完整演示。

桌面与手机之间的“知识口袋”承接跨端送达：电脑端可从 Agent 回答或当前学习内容收纳一条知识；在口袋中标记「感兴趣 / 还没弄懂」，再决定「发到微信，现在看」或「加入定期速览」。手机端会显示微信服务通知、适合手机阅读的短卡；排入速览的内容会优先补进每周速览。收纳动作本身不会发送。

桌面评审控件只存在于设备样机外框：指针移至屏幕下沿显示翻页、总览和全屏工具栏；移至右侧显示八个设计点跳转。第 4 点使用电脑端知识口袋截图，并可点「模拟点按」切到微信即时通知；随后可进入短读卡。键盘支持 ← / →、Page Up / Page Down、Home / End，O 打开总览、F 切换全屏。地址可用 `?point=8#briefing` 直达订阅设置演示。手机视口不显示这些演示控件，也不增加小程序入口。

## 体验路径

1. 任务发现：从当前开发任务出发，搜索、筛选并打开相关知识。
2. 知识卡微学习：用图解、练习和小题学习，也可收藏或标记「感兴趣 / 还没弄懂」。
3. 任务接续：查看学习进展，保存任务小结；复制小结与问题后回电脑端继续。
4. 电脑端知识口袋：从 Agent 回答或当前学习内容收纳知识，标记「感兴趣 / 还没弄懂」，选择立即发到微信或加入定期速览。
5. 即时送达：微信会话列表出现服务通知；点开后可进入来自电脑端的知识卡通知。
6. 手机短读卡：阅读知识点、来源和关联任务；点「我看懂了」记下理解状态。
7. 每周速览：一条昇腾开发重点资讯，加两张按电脑端安排与关注 / 存疑信号推荐的短知识卡。
8. 订阅设置：选择主题、星期和时间；确认后模拟微信授权，并回到消息列表呈现一条新到的未读通知。

七张知识卡覆盖扩展效率、梯度同步、有效 Batch、混合精度、并行策略、尾块和输入布局。吞吐、梯度等值用于概念演示，内容附公开延伸阅读。周报示例内容为静态策划素材，不代表实时资讯。任务、推荐、兴趣标记、主题偏好、订阅状态与交互均在本地运行；相关状态存储在当前浏览器 localStorage。桌面与手机样机通过同源 localStorage 在同一浏览器中模拟共享口袋；这不代表已实现不同设备间的账户同步。电脑端打开手机短读页和微信通知均为页面交互，未接入微信后台。

普通订阅消息不等于持续周推送。真实周期发送需要小程序类目符合平台要求并申请可用的长期订阅模板；当前页面只演示授权、通知和阅读回流。

## 文件

- `index.html`：页面与手机预览壳。
- `app.js`：路由、推荐、图解、收藏、小题、兴趣信号、电脑端知识口袋短读、微信通知、每周速览和任务小结。
- `knowledge.js`：知识内容、任务关联、周报示例主题和公开阅读链接。
- `styles.css`：独立样式与手机适配。
- `evidence/knowledge-pocket-entry-crop.png`：第 4 个设计点使用的电脑端知识口袋界面截图裁切。
- [知识供给侧服务蓝图（7 页可视化汇报）](./knowledge-provider-map.html)：独立的 Report PPT 风格材料。封面和学习发现资源卡使用内容图；供给链路、Demo 楼层映射、Knowledge Unit、交付通道与 P0–P2 建设顺序分别用流程图、字段结构图、分流图和时间轴表达。图片位于 `assets/knowledge-resources/`；Tabler 图标的 MIT 许可随资源保存。材料描述目标服务方案，不代表 Demo 已接入真实后端。
- `evidence/home-desktop.png`：核心学习章节与 HarmonyOS 风格状态栏样机。
- `evidence/review-overview-desktop.png`：七点版总览历史截图；当前八点版可在桌面总览中交互查看。

这是浏览器交互原型，可用于小程序设计评审。原生微信小程序工程及平台发布不在本版内。

本目录为构建免依赖的静态页面，使用 HTTP 静态服务器预览。JS 校验可执行 `node --check app.js` 和 `node --check knowledge.js`。
