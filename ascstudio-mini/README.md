# Ascend Studio · 口袋新知

面向手机的小程序交互 Demo，以知识卡推荐为首页，关联电脑端任务。手机上全屏显示；电脑端以小程序窗口呈现，便于评审。独立发布入口：`/AscendCANN/ascstudio-mini/`。

## 体验路径

1. 发现：搜索或筛选知识点，从任务上下文进入知识卡，也可以换一组推荐。
2. 知识卡：操作图解、回答理解题、收藏、编辑并保存任务小结。
3. 任务：切换推荐上下文，查看相关知识和已保存小结，复制小结与问题后到电脑端继续。
4. 我的：查看收藏、已理解知识与任务小结，刷新后保留。

七张知识卡覆盖扩展效率、梯度同步、有效 Batch、混合精度、并行策略、尾块和输入布局。吞吐、梯度等值用于概念演示，内容附公开延伸阅读。任务、推荐与交互均为本地示例；收藏和学习记录使用当前浏览器 localStorage，电脑端接续采用显式复制，不代表跨设备后台同步。

## 文件

- `index.html`：页面与手机预览壳。
- `app.js`：路由、推荐、图解、收藏、小题与任务小结。
- `knowledge.js`：知识内容、任务关联和公开阅读链接。
- `styles.css`：独立样式与手机适配。

这是浏览器交互原型，可用于小程序设计评审。原生微信小程序工程及平台发布不在本版内。

本目录为构建免依赖的静态页面，使用 HTTP 静态服务器预览。JS 校验可执行 `node --check app.js` 和 `node --check knowledge.js`。
