04 · 按使用方式分流
04A · WEB / SEARCH
公开发现可发现 → 可阅读 → 可引用搜索与 AI
找到权威内容
1控制抓取范围
robots.txt + sitemap.xml公开路径、规范 URL；robots 不负责鉴权
↓
2发布可读正文
HTML + Markdown同源内容、稳定标题锚点、代码与版本
↓
3描述内容语义
JSON-LD · Course类型与名称和页面正文保持一致
↓
4补充 AI 导航
llms.txt社区提案；支持它的客户端可继续找原文
04B · PRODUCT API
产品 API按环境筛选并解释资源学习发现
呈现匹配资源
1输入目标与环境
goal · CANN · chip · date缺失字段留空，不猜测兼容条件
↓
2定义接口契约
OpenAPI 3.1 + Schema统一鉴权、分页、字段与错误格式
↓
3分开查询与反馈
GET resources / events / compatibility收藏、完成等 POST signals 需用户同意
↓
4带依据呈现状态
verified / unknown / incompatible展示来源与范围；未知不静默当兼容
04C · AGENT / MCP
Agent知识、方法与任务回执可装配助手
执行可核查
1携带任务上下文
task · version · chip · error环境不全时先补齐或停止
↓
2Skill 组织方法
SKILL.md · trigger / steps / stop注明版本、成功信号与失败分支
↓
3MCP 连接知识与工具
Resources + read-only Tools查文档与兼容性；变更环境单独授权
↓
4形成 Evidence Receipt
status · source_refs · logs · next_action应用层核验；MCP 返回不等于任务通过
